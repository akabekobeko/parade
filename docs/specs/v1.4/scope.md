# v1.4 スコープ

v1.4 でやること・やらないことを定義します。

## 方針

お気に入りは **ユーザーがアプリの中で付ける印** です。曲の評価 (`rating`) は音声ファイルのタグに由来し、曲情報ダイアログで編集してファイルへ書き戻しますが、お気に入りは DB だけに持ち、ファイルには書きません。両者は独立しており、どちらを変えても他方は変わりません。

曲のお気に入りは `musics` テーブルのカラム、アルバムのお気に入りは専用テーブルに持ちます。アルバムは `musics` から動的に導出しており `albums` テーブルはありませんが、お気に入り用に `albums` を設けるのではなく、アルバムの同一性キーをそのまま主キーにした関連付けテーブル (`artist_initials` と同じ形) を足します ([データベース](architecture/database.md))。

UI の変更は Artists / Albums / Playlists の 3 ビューとアルバム情報ダイアログ、コンテンツ ツールバーに及びます。行の操作 (選択、再生、メニュー、Drag & Drop) は変えず、Star ボタンを足すだけにします。

## v1.4 でやること

### 曲のお気に入り

- `musics.favorite` カラムの追加と、再インポート・タグ編集で消えない保存 ([データベース](architecture/database.md))
- Artists / Albums の曲リスト行で、トラック番号の左隣の Star をクリックして切り替える ([曲のお気に入り](features/music-favorite.md))
- Playlists のテーブルにお気に入りカラムを足し、セルの Star で切り替え、ヘッダーのクリックでソートする ([Playlists のお気に入りカラム](features/playlist-favorite-column.md))

### アルバムのお気に入り

- `album_favorites` テーブルの追加と、曲がなくなったアルバムの行の GC ([データベース](architecture/database.md))
- アルバム情報ダイアログに Favorite の項目と Apply ボタンを足し、曲情報ダイアログと同じ form の流れで保存する ([アルバムのお気に入り](features/album-favorite.md))
- Artists のアルバム見出しに ON の印を出し、Albums 一覧のカードの Star で切り替える

### 絞り込み

- コンテンツ ツールバーの「曲を絞り込む」の左隣に Funnel アイコンのフィルター メニューを置き、「お気に入りのみ表示」をトグルする ([フィルター メニュー](features/filter-menu.md))
- Artists / Playlists は曲、Albums はアルバムをお気に入りで絞り込み、「曲を絞り込む」と AND で結合する ([お気に入りの絞り込み](architecture/favorite-filter.md))
- 絞り込み中の再生キューは「曲を絞り込む」と同じ扱いにする

### 公式サイト

- トップ ページの機能一覧にお気に入りを足し、見た目の変わるスクリーンショットを撮り直す ([公式サイトへの反映](features/web-site.md))

## v1.4 でやらないこと

| 機能 | 備考 |
| --- | --- |
| お気に入りのファイル タグへの書き出し | お気に入りはアプリ内の印。ID3 の POPM など形式ごとに意味が違うため扱わない |
| `rating` との連動 | 独立した値。お気に入り ON で星 5 にする、などはしない |
| 曲メニュー・右クリック メニューの「Favorite」項目 | 切り替えは Star ボタンから。複数選択をまとめて切り替える操作は v1.x で検討 |
| スマート プレイリストの条件 `favorite` | SQL の条件としては足しやすい (`m.favorite = 1`) が、v1.4 は表示と絞り込みに絞る。v1.x の候補 |
| 「お気に入りのみ表示」の永続化 | 「曲を絞り込む」と同じくセッション限りの表示状態 |
| Albums サイドバーのフィルター パネルへの追加 | 絞り込みはツールバーのフィルター メニューに統一する。`albumFilter` (設定に保存) には足さない |
| キーボード ショートカット | Star は `<button>` なので Tab と Enter / Space で操作できる。専用のショートカットは設けない |
| Playlists のお気に入りカラムの非表示 | 常に表示するカラム (pinned) にする。保存済みのカラム設定に新しいカラムを差し込む移行を避け、お気に入りを常に見せる ([Playlists のお気に入りカラム](features/playlist-favorite-column.md)) |
| アーティストのお気に入り | 対象は曲とアルバムのみ |
| プレイリストのお気に入り | 対象は曲とアルバムのみ |

## 非機能要件

- Star のクリックからビューへの反映まで、1 万曲規模でも再取得を待たないこと。曲は Renderer のキャッシュを差し替え、アルバムの一覧の再取得は絞り込み中だけ行う ([IPC](architecture/ipc.md))
- 再インポートと曲情報の編集 (ファイルの書き換えと再読み込み) でお気に入りが消えないこと
- アルバム名やアルバム アーティストの編集でアルバムのキーが変わっても、お気に入りが引き継がれること
- 「曲を絞り込む」とお気に入りの絞り込みを同時に使っても、絞り込みの順序で結果が変わらないこと
- DB のマイグレーションは 1 ファイル (005) で、`PRAGMA user_version` を 5 にする
