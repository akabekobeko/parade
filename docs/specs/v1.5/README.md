# v1.5

Parade v1.5 の仕様書です。プレーヤー バーにリピート再生ボタンを置き、キュー全体を繰り返す Repeat と、1 曲を繰り返す Repeat1 を切り替えられるようにします。あわせて、シャッフルとリピートをアプリケーション メニューから操作できるようにし、両方のモードを設定として保存します。

## テーマ

**いま聴いているアルバムやプレイリストを繰り返し、気に入った 1 曲を何度でも聴く。再生モードはメニューからも切り替えられ、次回起動時も覚えている。**

- プレーヤー バーのシャッフル ボタンの左隣にリピート ボタンを置き、クリックのたびに「無効 → Repeat → Repeat1 → 無効」と遷移する
- Repeat はカレント キュー (現在のアルバム、プレイリスト、アーティストの曲の並び) を末尾まで再生したら先頭から繰り返す
- Repeat1 は現在の曲が終わったら同じ曲をもう一度再生する
- リピートはシャッフルと独立したモードで、シャッフルは「並び」、リピートは「終端の挙動」を決める
- アプリケーション メニューの「コントロール」にシャッフルとリピートの項目を足し、現在のモードをチェックで表す
- シャッフルとリピートのモードを `settings.json` に保存し、次回起動時に復元する

## リリース

v1.5 はマイナーリリースです。機能 PR には `release:minor` ラベルを付与します ([リリース フロー](../../release.md))。DB のマイグレーションはありません。`settings.json` は項目が 1 つ増えるだけで、`version` は 1 のままです (未知の項目は sanitize で既定値になるため、古いバージョンへ戻しても壊れません)。
