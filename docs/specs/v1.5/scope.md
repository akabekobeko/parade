# v1.5 スコープ

v1.5 でやること・やらないことを定義します。

## 方針

リピートは **プレーヤーのモード** です。シャッフル モードと同じく PlayerProvider の state に持ち、どのビューから再生を始めても同じように効きます。

「アルバム、プレイリスト単位のリピート」は **カレント キューのリピート** として実装します。キューはアルバム再生、プレイリスト再生、アーティスト再生、曲クリックのたびにビューの並びで置き換わるため ([プレイリスト](../v1.0/features/playlist.md))、「いま聴いている単位」はキューそのものです。アーティストの全曲から再生した場合はアーティストの全曲が繰り返されます。

エンジンは変えません。リピートは「曲が自然に終わったとき次に何をするか」の判断で、PlayerProvider の責務です ([オーディオ エンジン](../v1.0/renderer/audio-engine.md) の責務境界)。

シャッフルとリピートは **再生モード** としてひとまとめに扱います。アプリケーション メニューの項目と `settings.json` への保存は両方に対して行い、v1.0 からあるシャッフルも v1.5 でメニューと保存の対象にします。

## v1.5 でやること

### リピート モード

- `PlayerState` に `repeat` (`off` / `all` / `one`) を足し、`cycleRepeat` コマンドで `off → all → one → off` と切り替える。メニューからは `setRepeat(mode)` で直接指定する ([リピート モード](architecture/repeat-mode.md))
- `all` はキュー末尾の曲が終わったらキュー先頭の曲を再生する。前曲 / 次曲ボタンも末尾と先頭でつながる
- `one` は現在の曲が終わったら同じ曲を先頭から再生する。前曲 / 次曲ボタンは無効のときと同じ (明示的な移動はリピートしない)
- シャッフル、キューの置換 / 挿入 / 追加 / クリアとは独立に動く

### リピート ボタン

- プレーヤー バーのシャッフル ボタンの左隣に `RepeatButton` を置く ([リピート ボタン](features/repeat-button.md))
- 無効は Lucide の `Repeat`、`all` は `Repeat` + glow、`one` は `Repeat1` + glow で表す
- 文言 (ツールチップと `aria-label`) を en / ja に足す

### アプリケーション メニュー

- 「コントロール」メニューに「シャッフル」(チェック項目) と「リピート」(なし / 全曲 / 1 曲のラジオ項目のサブメニュー) を足す ([コントロール メニュー](features/controls-menu.md))
- `mp:menu:setState` にシャッフルとリピートの状態を足し、メニューのチェックがプレーヤー バーの表示と常に一致するようにする
- `mp:menu:action` に `toggleShuffle` / `setRepeat*` を足し、ブートストラップの経路でプレーヤーのコマンドへつなぐ

### 永続化

- `AppSettings.playback` (`{ shuffle, repeat }`) を足し、モードの変更のたびに保存する ([再生モードの永続化](architecture/playback-settings.md))
- 起動時に PlayerProvider の初期 state へ流し込み、プレーヤー バーとメニューに復元した値を出す
- 保存するのはモードだけで、キュー、現在曲、再生位置は保存しない

### 公式サイト

- トップ ページの「Play your way」の説明にリピートを足し、プレーヤー バーが写るスクリーンショットを撮り直す ([公式サイトへの反映](features/web-site.md))

## v1.5 でやらないこと

| 機能 | 備考 |
| --- | --- |
| キュー、現在曲、再生位置の復元 | 保存するのはシャッフルとリピートのモードだけ。「前回の続きから」は v1.x で検討する |
| 音量の永続化 | 再生モードとは別の話なので v1.5 には含めない。足すなら `playback.volume` に置く |
| メニュー項目のキーボード ショートカット | Apple Music もシャッフル / リピートには割り当てていない。メニューを開けば十分で、誤操作でモードが変わるのを避ける |
| MediaSession との連携 | MediaSession API にシャッフルやリピートの action はない。OS のメディア コントロールからは切り替えられない |
| `all` で先頭へ戻るときの再シャッフル | シャッフル中も同じ並びを繰り返す。キュー ポップオーバーの並びが変わらず予測しやすい。再シャッフルは v1.x の候補 |
| ギャップレスなループ | `one` は曲の切り替えと同じくエンジンを作り直す。曲の境目に短い無音が入る |
| A-B リピート、再生回数の指定 | 対象外 |
| プレーヤー バーの右クリック メニューの項目 | 停止のみのまま。シャッフルとリピートはボタンとアプリケーション メニューから |
| 設定ページの項目 | 再生モードはプレーヤーの操作であり、設定ページには置かない |

## 非機能要件

- 曲の終端の判断は純関数にし、モード × キューの状態の組み合わせをユニット テストで押さえる
- モードの切り替えは再生を止めない。再生中に `one` にすれば今の曲から繰り返し、`off` に戻せば次の曲へ進む
- ボタン、メニュー、設定ファイルの 3 か所が同じモードを示す。どこから切り替えても state は 1 つ (PlayerProvider) で、メニューと設定は state の変更に追従する
- ボタンの見た目はシャッフル ボタンと同じ `GlowIconButton` で、ライト / ダーク両テーマで無効と有効が見分けられる
- `settings.json` の `playback` が壊れていても起動に影響せず、既定値 (シャッフル OFF、リピートなし) になる
